# 🎯 Overwatch 2 AI TriggerBot (YOLOv8 + TensorRT)

Опенсорсный триггер-бот для Overwatch 2, основанный на нейросети YOLOv8/YOLO11. Проект использует компьютерное зрение для обнаружения врагов в реальном времени и выполняет автоматический выстрел при наведении прицела.

## 🚀 Возможности
*   **Высокая скорость:** Использование TensorRT (`.engine`) и библиотеки `mss` для захвата экрана позволяет достигать 60+ FPS.
*   **Нейросеть:** Модель обучена распознавать героев Overwatch 2.
*   **Удобный интерфейс:** Графический интерфейс на базе Tkinter.
*   **Настройка:** Регулировка порога уверенности (Confidence) и радиуса зоны поражения.
*   **Защита от сбоев:** Логика "памяти цели" предотвращает мигание рамок при потере объекта.

## 🛠️ Установка и запуск

1.  Установите [Python 3.12](https://www.python.org/downloads/). При установке обязательно поставьте галочку **"Add Python to PATH"**.
2.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/sorryplsssssss/Overwatch2-YOLO-TriggerBot.git
    cd Overwatch2-YOLO-TriggerBot

    Создайте и активируйте виртуальное окружение:
    python -m venv venv
venv\Scripts\activate


Установите зависимости:
pip install -r requirements.txt

Скачайте модель: Скачайте файл v2.engine по ссылке ниже и положите его в корень папки с проектом.
[📥 Скачать модель v2.engine (Google Drive)](https://drive.google.com/file/d/1_0KrH-xr5iUZxlqzT1WZZQJLgRtVnXrB/view?usp=sharing)

Запустите программу:
python BotApp.py

🎮 Как использовать
Запустите Overwatch 2.

В настройках видео обязательно включите режим «Оконный без рамки» (Borderless Windowed).

Зайдите на тренировочный полигон.

Запустите BotApp.py, нажмите «▶ ЗАПУСТИТЬ БОТА».

Наведите прицел на врага. Когда цель окажется в зоне поражения, бот автоматически выстрелит.

🧠 Обучение своей модели (Для продвинутых)
Если вы хотите обучить модель на своих скриншотах:

Подготовьте датасет в формате YOLO.

Запустите train.py для обучения.

Конвертируйте полученный best.pt в best.engine с помощью convert.py для максимальной скорости.
